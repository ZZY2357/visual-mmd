# 09 验收收尾

来源：`spec.md` 的「验收场景」。本票不写功能，只做**端到端验收**与**回归确认**。

## 完成判据（= spec 的两个场景，闭眼走完）

### 场景 A（类图）

> 加类 → 加两个成员 → 连到另一个类 → **双击线上标上 `1..*` 与标签** → 点选这条线并在右侧改成 `*--`。

**已知注意点**：`1..*` 与标签在实测中是**两组不同的文本**——基数 `"1"` / `"*"` 位于
`g.edgeTerminals > foreignObject > span.edgeLabel`，**全程无 data-id**；而标签在
`g.edgeLabel > g[data-id]`（与 edgePaths 共享 id）。
**场景 A 里"双击线上标上基数"能否成立取决于工单 02 对基数命中的裁定**——若 02 判定基数不可命中，
场景 A 需改为"点选这条线并在右侧表单标基数"，并在本票记录该调整。

### 场景 B（时序图）

> 加参与者 → 互发三条消息 → 包一个 alt 块并写条件 → 右键一条消息改箭头并删掉它。
