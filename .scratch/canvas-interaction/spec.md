# Spec: 画布交互（canvas-interaction）

来源：grilling 会话（2026-09-27），共识已由用户确认。术语变更已落入 `CONTEXT.md`
（右键菜单、连线模式、内联编辑、视图；属性面板不再承担添加入口）。

## 需求清单

1. **连线可点选**（bug 修复）：目前 flowchart 连线点不中。给边加透明宽命中路径
   （~12px），点击选中并联动右侧 EdgeForm。
2. **classDef 应用到节点**：节点属性表单新增"应用样式"多选下拉（列出全部 classDef）。
   勾选落码为独立 `class 节点 样式名` 语句（手术式改写，逐字保留）；取消勾选删除对应
   语句。一个节点可挂多个样式。
3. **画布视图**：初始整图自适应居中（fit）；纯滚轮以鼠标为锚点缩放（0.25–4 倍，不做
   Ctrl 区分）；拖拽背景平移；提供"适应窗口"按钮；缩放状态不持久化。导出 SVG/PNG
   始终整图，与视图无关。
4. **画布键盘焦点体系**：画布容器 `tabindex=0`，点击画布后持有焦点；Tab/Enter/Del 仅
   在画布聚焦时拦截生效，焦点在代码面板或输入框时完全不干扰。Flowchart 语义：
   - Tab = 从选中节点连出新节点（`选中 --> 新`）
   - Enter = 选中节点有父节点时 `父 --> 新`；无入边时从选中节点连出。
5. **新节点立即命名**：Tab/Enter/菜单添加节点后，直接在画布原位浮出输入框（复用双击
   内联编辑），回车/失焦确认；落码先用默认名，确认后改文本。
6. **双击内联编辑**：双击节点原位浮输入框编辑显示文本，回车/失焦提交。覆盖
   flowchart + mindmap（sequence/class 本轮不动）。
7. **mindmap 键盘**：结构树中焦点在树节点上时，Tab 加子节点 / Enter 加同级节点
   （preventDefault）；mindmap 画布点选启用，画布键盘同 flowchart 方案。
8. **右键菜单**：单一菜单随右键目标变化——空白处 = 添加节点/添加连线（进入连线模式：
   依次点起终点，Esc 取消；节点右键可直接"从这里连线"）/添加样式（浮出小表单先定名称
   颜色再落码）/添加子图；元素上 = 编辑文本、删除、应用样式等。属性面板"添加"按钮组
   彻底移除，结构树保留。

## 惯例决定

- 选中态：外圈描边高亮，节点/连线/子图统一。
- 移除样式时同步清理对应 `class` 语句。
- mindmap 新节点按缩进层级落码。
- 缩放范围 0.25–4，不持久化。
