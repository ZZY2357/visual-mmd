# 双面板双向同步：最后操作者获胜，错误冻结

> **状态：核心语义已被 [ADR-0008](0008-source-code-is-the-single-source-of-truth.md) 取代**（源码为唯一真相源，不再是"最后操作者获胜"）；错误冻结策略（画布停在最近合法状态）仍有效。

代码面板（左）与画布（右）双向实时同步，无"应用"按钮：焦点/操作在哪一侧，该侧就是当前真相源——编辑代码实时刷新画布，操作表单实时重写代码。这一决定源于产品核心价值"边画边学 Mermaid 语法"：用户改动可视化元素时立刻看到对应语法变化，反之亦然。

错误处理：代码面板出现语法错误时，画布冻结显示最近一次合法状态的图，代码面板内联标红错误行；恢复合法后立即继续同步。
