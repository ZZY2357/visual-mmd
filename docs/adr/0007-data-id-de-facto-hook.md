# 画布选中依赖 data-id 事实约定，边选中以结构树为主

> **状态：accepted**

"点击画布元素选中编辑"依赖 mermaid 渲染 SVG 上的 `data-id` 属性（值即源码节点 id）。调研确认（2026-09，issue #7077）：节点上的 data-id 是 mermaid 团队有意提供的事实约定，但未文档化、无稳定性承诺，且**边没有对应映射**（issue #5497 仍 open）。

因此：节点点击选中按 data-id 实现，升级 mermaid 大版本时必须回归验证；边的选中以结构树为主入口，画布侧对边只做尽力而为的 DOM 匹配，不作为承诺能力。悬停联动（roadmap）受同一约束制约。
