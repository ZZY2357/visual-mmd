# 模型级统一撤销/重做栈

> **状态：superseded-by-0008** —— 撤销已改为代码快照单栈（[ADR-0008](0008-source-code-is-the-single-source-of-truth.md)），不再有独立的模型级撤销栈。

所有编辑操作（表单操作、画布选中/删除/快捷键、代码面板的输入落地）统一产生可视化模型的变更，进入单一历史栈；Ctrl+Z 撤销的是图表状态，代码面板内的连续文本输入按输入会话合并为一个变更。

这是有意的架构偏差：更简单的做法是只依赖 CodeMirror 的文本级撤销、表单操作不设撤销，但可视化编辑器缺少模型级撤销会被视为半成品，且后续再补命令栈的成本远高于第一天就架在模型层。
