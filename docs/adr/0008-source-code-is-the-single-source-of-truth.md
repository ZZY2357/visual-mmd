# Mermaid 源码是唯一真相源，手术式局部编辑

> **状态：accepted**

推翻此前的"最后操作者获胜"语义（ADR-0003）与模型级撤销栈（ADR-0006）：Mermaid 源码是产品的最终交付物，也是编辑器内唯一真相源；可视化模型是源码解析出的只读**投影**，一切编辑——表单操作、画布操作、代码面板输入——最终都表达为对源码的修改。解析器为每个元素记录源码文本区间（span），表单/画布编辑只重写受影响元素的区间，未触碰的文本（注释、空行、用户的排序缩进习惯、无法解析的语法）逐字保留。

可测试承诺：解析后不做任何修改再重组装，输出与输入逐字相同（verbatim identity test）。

派生决策：
- 撤销/重做 = 代码快照单栈；表单/画布/代码编辑均产生快照入栈，连续代码输入按输入会话合并。
- 源码存在语法错误时，投影停留在最近一次合法状态，属性面板整体禁用并提示跳转到错误行，修复后立即恢复编辑。
- 此前的"透传片段"合并机制消解：无法映射到投影的语法不参与解析重组装，自然原样保留，无需额外机制。
